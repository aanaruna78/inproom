
# Development and Security Authorization

This project involves authorized software engineering,
security assessment, testing, and remediation.

Operating boundaries:
- Work only on systems, repositories, and environments
  that I own or am explicitly authorized to assess.
- Follow secure development practices.
- Do not access unauthorized third-party systems.
- Prefer isolated testing environments for security validation.
- Support vulnerability analysis, defensive testing,
  remediation, and verification.
- Clearly identify security risks and recommend mitigations.

Workflow expectations:
- Do not repeatedly request confirmation of the established
  project scope unless a specific action requires it.
- Proceed with legitimate engineering tasks within the
  authorized boundaries.
- If a requested technique is restricted, explain the
  limitation briefly and offer a safe implementation path.
